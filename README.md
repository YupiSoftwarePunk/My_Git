**MyGit** — это лёгкая учебная система контроля версий, вдохновлённая Git.  
Она позволяет сохранять снимки проекта, переключаться между коммитами и отслеживать изменения файлов.  
Все данные хранятся в скрытой директории **`.mygit`**.

---

## 🚀 Возможности

- Инициализация репозитория  
- Настройка имени пользователя  
- Добавление файлов (одного, нескольких или всех)  
- Создание коммитов со снимком состояния проекта  
- Полный откат файлов через `checkout`  
- Просмотр истории коммитов  
- Просмотр статуса файлов  
- Цветной CLI‑интерфейс  

---

## 📁 Структура репозитория

```
.mygit/
 ├── HEAD            # текущий коммит
 ├── objects/        # blob, tree и commit объекты
 └── config.txt      # имя пользователя
```

---

## 📌 Основные команды

| Команда | Описание |
|--------|----------|
| `config <username>` | Установить имя пользователя |
| `init` | Инициализировать репозиторий |
| `add <file>` | Добавить файл |
| `add .` / `add --all` | Добавить все файлы проекта |
| `commit <message>` | Создать коммит |
| `log` | Показать историю коммитов |
| `checkout <hash>` | Переключиться на указанный коммит |
| `status` | Показать отслеживаемые и новые файлы |
| `cd <path>` | Сменить рабочую директорию |
| `help` | Список команд |
| `exit` | Выход из программы |

---

## 🧠 Как это работает

- **Blob** — объект с содержимым файла  
- **Tree** — снимок всех файлов проекта  
- **Commit** — ссылка на tree + автор + сообщение + родитель  
- **HEAD** — указывает на последний коммит  
- **checkout** — удаляет текущие файлы и восстанавливает их из tree

## 📘 Пример использования

```text
mygit> init
mygit> config Yupi
mygit> add .
mygit> commit initial commit

# ...изменяем файлы...

mygit> add .
mygit> commit update

mygit> log
mygit> checkout <старый_коммит>
```
